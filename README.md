\# 校园二手交易系统核心模块测试



本项目配合开发完成校园二手交易系统的质量保障工作，覆盖登录、商品管理、订单交易三大核心模块。



\## 技术栈

\- Python + Selenium：核心模块自动化回归

\- Postman：接口测试（参数与返回值校验）

\- MySQL：数据存储一致性校验



\## 目录说明

\- testcases/          # 测试用例设计（等价类、边界值）

\- selenium\_scripts/   # Selenium 自动化脚本

\- postman/            # Postman collection + environment

\- sql\_verify/         # MySQL 数据校验语句

\- defects/            # 缺陷跟踪

\- reports/            # 测试报告与截图

\- docs/               # 需求、接口文档
